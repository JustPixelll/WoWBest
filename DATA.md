# WoWBest catalog

The November 15, 2026 catalog targets World of Warcraft: Forever 1.60.1. Its default pool contains **4,733 distinct equipment IDs across 6,501 routes**. Each route uses a Forever source or requires positive evidence from the current character. Turning on **Include unconfirmed sources** adds 2,218 possible world-drop routes, including 2,209 additional IDs, for 6,942 distinct items and 8,719 routes overall. Several routes can lead to the same item. The full generated catalog ships with the addon. A player never needs to fetch data, install Python or install another addon. [Coverage by level and remaining gaps](COVERAGE.md)

| Acquisition | Routes | Evidence and typical detail |
| --- | ---: | --- |
| Quest reward | 1,927 | Launch server reward ID, pick-one or fixed reward, minimum level, quest title, and available class, race and side requirements |
| Dungeon | 759 | Launch boss rolls, other observed instance corpses, and named Forever dungeon listings |
| Crafted | 1,282 | Recipe, creating profession and skill rank. 594 high-rank routes also require the character to know the recipe and have sufficient materials |
| World drop or treasure | 997 | Launch corpse loot, opened outdoor treasure or gear found inside a trunk that players caught while fishing |
| Vendor | 1,319 | Observed merchants, corroborated quartermasters, location and recorded price where available |
| PvP | 217 | Battleground quartermaster stock on both factions with the required reputation or rank |

Quest, profession and NPC names in the route text are in English. The item name, link, tooltip, level, equipment position and usable-item checks come from the current client. Some item IDs have multiple valid sellers or bosses. A vendor price reflects an observed standing or discount, and a world-drop source identifies one observed creature that dropped the item.

## Coverage and access

- **Quests.** The launch server supplies the reward, quest level, acceptance level and race mask. The main routes have an observed offer, a recorded turn-in, or a named matching route in ForeverLevelingBiS. Where evidence for access is missing, 675 additional reward rows on 591 distinct items require the exact quest to be in the character’s log. This also applies to level-50+ quests with no observed offer or turn-in. For example, a character holding *The Monster Surfaces* in Riverglades can plan for Bottle of Powderfuse Port. Merely receiving quest data from the server does not establish an offer. The generator omits event, raid and profession quests with unmodeled gates. It includes the two verified weekly rare-fish equipment exchanges under the conditions below. It handles the minimum acceptance level, status of one-time rewards, reported class or race masks, and mutually exclusive choices in the same reward window. Some chains involve prerequisite quests, group kills, or permanent choices between separate quest lines. The catalog cannot establish every one of those conditions.
- **Dungeon access.** Original instances use published entry thresholds. The nine new instances use the lower end of their announced level ranges as a conservative planning threshold when no verified portal minimum is available. Certain named quests or bosses also require keys, a summon, a particular encounter, or a group. Published dungeon data can change with hotfixes. [Dungeon overview](https://www.wowhead.com/forever/guide/dungeons-overview-locations-details) · [Blizzard launch announcement](https://worldofwarcraft.blizzard.com/en-us/news/24315820)
- **Crafts.** Independent Forever sources identify the crafting recipe or a launch trainer reports teaching it. At skill 226 or higher, a recipe absent from the launch trainer observations needs live personal evidence. For these 594 routes the addon checks the player’s crafting skill, whether that exact recipe is learned, and whether the client currently reports enough materials to make it. Arcanite Reaper uses Blacksmithing 300 and spell 16994. Profession access and materials are checked per recipe. Two different recipes may consume the same materials. Tradeable crafts with ordinary documented routes can be commissioned or purchased from other players. A live auction listing can supply an independent route for a high-end tradeable craft. A bind-on-pickup craft requires the character to know the recipe and meet its profession rank for the current set. A trainer-taught recipe may appear in optional paths before it is learned. The generator keeps the wearer requirement, recipe spell and rank, and personal crafting requirement separately. Five common items absent from the uncommon gear cache have documented Forever auction listings, including Copper Axe and Linen Belt. Current listings and prices vary. [Copper Axe](https://forevermastery.com/en/recipes/2738-copper-axe) · [Tradeable low-level weapons](https://everloot.app/tools/auctions?class=weapons&sort=market) · [Tradeable common armor](https://everloot.app/tools/auctions?class=armor&house=horde&quality=common&sub=cloth)
- **World loot.** Corpse drops need a named NPC, a positive unshared drop, and outdoor positions for that loot or consistent observed habitat for the NPC. Dungeon corpses follow the same rule using an identified instance. Pickpocketing and skinning use separate loot keys. There are 41 additional routes from opened outdoor treasure and fishing trunks. For example, Aurora Cowl dropped from a Solid Chest in Stranglethorn Vale. An Iron Bound Trunk caught on the Stranglethorn mainland can yield Gloom Reaper, with Fishing 130 required for that route. Other characters also caught the trunk in the Barrens. Two observations are required for fishing gear, one for catching the trunk and another for finding the item inside. Journeyman Fishing becomes trainable at character level 10 and Fishing 50. [Loot observations and field definitions](https://github.com/JIVESCORP/eg-link-output-wowf/blob/ea970da071079b32e56f349e09648ff0e314b351/DATASETS.md#loot) · [Forever fishing skill by zone](https://www.wowhead.com/forever/guide/professions/fishing/overview-leveling)
- **Include unconfirmed sources.** This optional switch starts off. Each lead requires a valid Forever launch item response, a bind-on-equip Forever tooltip, a Forever source listed exclusively as a drop, and the same item ID listed exclusively under Classic Era world drops. The label identifies the historical evidence and the unconfirmed Forever origin. A confirmed outdoor or container observation supersedes this lead for the item. Random suffixes vary on individual copies. The snapshot excludes invalidated IDs, identified unavailable raid rewards and unverified Alterac Valley quest exchanges. Raid openings, holidays, newly discovered NPCs and future patches will require refreshed source data.
- **Merchants and PvP.** The rank and reputation checks apply to both factions’ battleground quartermasters, including the League of Arathor and Theramore Expeditionary Force. Steamwheedle quartermasters require the relevant goblin-town standing. Gelvas Grimegate’s five Darkmoon Prize Ticket exchanges use the Events and Vendors filters. WoWBest verifies Gelvas’s open merchant window and the player’s tickets. [League of Arathor](https://kovarel.com/wow-forever/factions/509-the-league-of-arathor) · [Theramore Expeditionary Force](https://kovarel.com/wow-forever/factions/2799-theramore-expeditionary-force) · [Steamwheedle standing and quartermasters](https://github.com/fitzforge/polestar/blob/19bd636e7d6f33231770f6029c76d2d4dfc63798/guides/forever/reputation/steamwheedle-cartel.guide)

## Source filters

The source filter applies to each way of obtaining an item. A dungeon boss drop uses **Dungeons**. A quest that requires killing that boss uses **Quests** and **Dungeons**, even when the reward comes from a quest giver in town. In this build, 448 reward routes from 190 quests carry both tags, including nine reviewed chains with a required dungeon step before the reward. *Delivery to Ridgewell* follows the retrieval of Doomrigger’s Clasp inside Upper Blackrock Spire. The generator verifies the reviewed chains against the launch server's quest IDs and links. Chausses of Westfall require Edwin VanCleef's head. The Axe of Orgrimmar requires an earlier Ragefire Chasm run. [Launch quest records](https://github.com/JIVESCORP/eg-link-output-wowf/blob/ea970da071079b32e56f349e09648ff0e314b351/data/wowf/1.60.1.70938/quests.enUS.json) · [Hidden Enemies boss objective](https://www.wowhead.com/forever/quest=5728) · [Upper Blackrock Spire quest guide](https://www.wowhead.com/forever/guide/upper-blackrock-spire-dungeon-overview-location-rewards)

Some quests in a dungeon category have outdoor ways to complete them. *Oh Brother…*, *Collecting Memories*, *Red Silk Bandanas*, *Serpentbloom* and *Deviate Hides* have launch objective progress on the open-world map. The Uldaman approach has outdoor urns, a tablet and power-stone mobs. *Researching the Corruption* also has outdoor targets. Those rewards remain under **Quests** when dungeons are off. The giver's location alone does not classify a quest. [Observed objective locations](https://github.com/JIVESCORP/eg-link-output-wowf/blob/ea970da071079b32e56f349e09648ff0e314b351/data/wowf/1.60.1.70888/objectives.json) · [Uldaman approaches](https://www.icy-veins.com/wow-classic/uldaman-quests-guide) · [Uldaman urns](https://www.zockify.com/classic/dungeons/uldaman/) · [Blackfathom Deeps objectives](https://www.icy-veins.com/wow-forever/blackfathom-deeps-quests/)

A single item can have independent routes. For example, a Slitherblade Naga dropped Cutthroat's Belt outdoors and Death Speaker Jargba dropped it in Razorfen Kraul. Turning off Dungeons leaves the outdoor route. Commissionable crafts remain under **Crafted** because another player can supply the item even when their recipe or materials came from a dungeon. An actual eligible auction listing is a separate route. PvP quartermasters use **PvP**. Ordinary currency vendors use **Vendors** and show their recorded prices. Source filters do not calculate how a character earns future currency or the origins of purchased reagents.

## Set data and scoring

The set index contains 1,577 member IDs across 274 sets, including sets that can enter through a character’s bags or a detailed Auction House search. A set entry supplies membership and threshold facts. A character still needs an eligible source for each individual piece. Of 780 threshold effects, 389 have numerical models. The others remain visible when activated even when their effect has no assigned score. [Set sources and rebuild instructions](WoWBest/licenses/SET-DATA.txt)

## Reproduce the catalog

Use **Python 3.10+** and Git. These commands can be run from the root of a checked-out WoWBest repository on Windows (PowerShell), macOS or Linux. Put the upstream checkouts outside the addon. They contain the source data for every build, so a full checkout of the first repository may be large.

```text
git clone --filter=blob:none --no-checkout https://github.com/JIVESCORP/eg-link-output-wowf.git ../wowbest-eg
git -C ../wowbest-eg sparse-checkout init --cone
git -C ../wowbest-eg sparse-checkout set data/wowf/1.60.1.70790 data/wowf/1.60.1.70840 data/wowf/1.60.1.70862 data/wowf/1.60.1.70888 data/wowf/1.60.1.70938
git -C ../wowbest-eg checkout ea970da071079b32e56f349e09648ff0e314b351
git clone --filter=blob:none --no-checkout https://github.com/fitzforge/polestar.git ../wowbest-polestar
git -C ../wowbest-polestar sparse-checkout init --cone
git -C ../wowbest-polestar sparse-checkout set addon/Polestar_ItemDB
git -C ../wowbest-polestar checkout 19bd636e7d6f33231770f6029c76d2d4dfc63798
git clone --filter=blob:none --no-checkout https://github.com/Napalmsteak/WoW-Classic-Item-Caches.git ../wowbest-cache
git -C ../wowbest-cache sparse-checkout init --no-cone
git -C ../wowbest-cache sparse-checkout set "/Forever Cache.json" "/Classic Era Cache.json"
git -C ../wowbest-cache checkout eff4560809de2e852e9164183e3edf5a795edd20
python tools/build_catalog.py --polestar ../wowbest-polestar --observations ../wowbest-eg --cache ../wowbest-cache
python tools/build_tooltip_stats.py --cache ../wowbest-cache
```

The catalog generator validates the three pinned commit IDs and writes `WoWBest/Catalog.lua`. Its expected SHA-256 is `cab24c068dec9d8878c2653e2ba7346c47729f4efbbfbde8a50a8acafcba8f99`. The second command uses the same pinned Forever cache to rebuild `WoWBest/TooltipStats.lua`, which supplies missing base-item stats and weapon damage. The addon checks the actual item link when scoring a particular copy. See [How WoWBest scores gear](SCORING.md) for the weighting assumptions. To update the snapshot, review upstream changes, adjust the pins and launch-build cutoff, recheck current dungeon and raid access, regenerate, and run the regression tests before shipping.
