WoWBest set metadata snapshot — November 14, 2026

Only set names, IDs, member IDs, thresholds, effect IDs and numeric mechanics
are imported. WoWBest uses its own short labels/weighted stat mappings. Detailed
conditional spell descriptions are requested from the user's installed client.
All game content and trademarks belong to Blizzard Entertainment.

Rebuild from the repository root:
python tools/build_sets.py --cache "/path/to/Forever Cache.json"
The script checks the SHA-256 and regenerates WoWBest/SetData.lua. SetBonuses.lua
checks the player's actual profession rank for profession-locked thresholds.

A stored set is membership metadata only. Some sets exist as records in the
Forever client without an obtainable source in the current phase. The planner
works with eligible catalog routes and actual owned/Auction House items.
Effects with unknown uptime, condition-specific utility or no profile weights
can influence practical decisions. The details view retains their spell names
and available live text alongside the scored thresholds.
